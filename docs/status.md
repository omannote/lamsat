## دوال الخادم المنشورة

| الدالة | الغرض | الحالة |
|---|---|---|
| `admin-users` | إنشاء مستخدم وتغيير رقمه السري بصلاحية المالك (مفتاح الخدمة في الخادم فقط) | منشورة، لم تُجرَّب بطلب حقيقي |
| `notify-worker` | معالجة إشعارات الفواتير: واتساب Cloud API ثم iSmartSMS عند الفشل | منشورة؛ بلا مفاتيح المزوّد تسجّل «تجريبي» ولا ترسل |

أسرار مطلوبة للإرسال الحقيقي (Supabase ← Edge Functions ← Secrets): `WHATSAPP_TOKEN`، `WHATSAPP_PHONE_ID`، `ISMART_USER`، `ISMART_PASSWORD`، `ISMART_HEADER`، و`WORKER_SECRET` للجدولة. قالب واتساب المعتمد باسم `invoice_issued` بثلاثة متغيرات: اسم العميل، رقم الفاتورة، الإجمالي.

## ما لم يُبنَ بعد

- **أوامر العمل والعربون** (أمر تركيب، حالات العمل، تسوية العربون في الفاتورة).
- **مستند تصحيح الفاتورة** المستقل — البديل إلغاء أو مرتجع ثم إعادة إصدار.
- صفحة القيود ودليل الحسابات وسجل التدقيق في الواجهة (البيانات مسجلة في القاعدة).
- **جدولة عامل الإشعارات** تلقائيًا (التشغيل الآن يدوي من الإعدادات)، وإشعارات غير الفاتورة.
- **النسخ الاحتياطي الآلي** خارج Supabase (الخطة في `docs/supabase-and-backup.md`؛ الخطة المجانية بلا نسخ يومية).
- **تطبيق العميل والتنبيه الجغرافي وتطبيق المالك للجوال** (المرحلة 6): تطبيقات جوال مستقلة لم يبدأ العمل عليها.
- لوحة الإدارة على الويب لم تُحدَّث بهذه الإضافات ولم تُنشر؛ التطبيق يغطي وظائفها الآن.

## قرارات محسومة

- **اتصال فقط**: لا يعمل النظام بلا إنترنت (لا قاعدة محلية ولا مزامنة).
- **الدخول باسم مستخدم ورقم سري من 8 خانات على الأقل** (لا PIN ولا بريد). اسم المستخدم هو الجزء قبل `@` في حساب Supabase، والتطبيق يلحق النطاق الداخلي تلقائيًا. الحد الأدنى يُفرض في شاشتي الدخول، ويجب ضبطه أيضًا في Supabase (Authentication ← Sign In / Providers ← Email ← Minimum password length = 8) وفي شاشة إدارة المستخدمين عند بنائها.

## قرارات الإصدار 2 (اعتمدها المالك 2026-11-27)

الخطة الكاملة في مستند «لمسات — خطة ما قبل الكود (الإصدار 2)».

- قاعدة بيانات جديدة للإصدار 2؛ بيانات النسخة الحالية لا تُرحَّل.
- الدخول: اسم مستخدم ورقم سري (8+) لأول دخول على الجهاز، ثم PIN من 4 خانات للتبديل السريع.
- التكلفة: المتوسط المرجّح المتحرك، بعد موافقة المحاسب.
- الضريبة تُضبط من الإعدادات بواسطة المالك أو مدير الفرع (مطبّق).
- واتساب: زر الإرسال عبر واتساب ويب هو الأساس (مطبّق)؛ الإرسال الآلي عبر Cloud API خيار في الإعدادات يُفعَّل لاحقًا.
- Supabase: الخطة المجانية الآن، وتُراجع عند التشغيل الفعلي.
